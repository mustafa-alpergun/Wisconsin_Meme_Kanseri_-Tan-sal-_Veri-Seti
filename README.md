Hello 👋

In this project, I developed a machine learning model that predicts whether a breast tumor is benign or malignant based on medical measurement data.

🚀 Project Overview:
🔹 Model: Built using the K-Nearest Neighbors (KNN) classification algorithm.
🔹 Objective: Automatically classify tumor diagnosis using patient measurement features.
🔹 Dataset: Breast Cancer Wisconsin Dataset
🔹 Preprocessing Steps:

Removed unnecessary columns

Converted categorical diagnosis labels into numerical format

Split dataset into training and testing sets (80% - 20%)

Applied feature scaling using StandardScaler

🔹 Performance Metric:
Evaluated using Accuracy Score.

🔹 Key Feature:
The model not only evaluates test performance but also predicts the diagnosis for a new patient’s measurements, providing clear output:

Malignant (M)

Benign (B)

🛠️ Tech Stack:
Python, Pandas, NumPy, Scikit-learn

Feel free to review the code and share your feedback!


Türkçe 🇹🇷

Merhaba 👋

Bu projede, makine öğrenmesi kullanarak meme kanseri verileri üzerinden tümörün iyi huylu (Benign) ya da kötü huylu (Malignant) olduğunu tahmin eden bir sınıflandırma modeli geliştirdim.

🚀 Proje Detayları:
🔹 Model: K-En Yakın Komşu (KNN) algoritması kullanılarak geliştirildi.
🔹 Amaç: Hastaya ait ölçüm değerlerine göre tümör teşhisini otomatik olarak sınıflandırmak.
🔹 Veri Seti: Breast Cancer Wisconsin Dataset kullanıldı.
🔹 Ön İşleme:

Gereksiz sütunlar kaldırıldı.

Hedef değişken (M/B) sayısal formata dönüştürüldü.

Veriler eğitim ve test olarak ayrıldı (%80 - %20).

StandardScaler ile ölçeklendirme uygulandı.

🔹 Model Performansı:
Accuracy (Doğruluk Oranı) metriği ile değerlendirildi.

🔹 Ek Özellik:
Model yalnızca test verisi üzerinde değerlendirilmekle kalmıyor; yeni bir hastaya ait ölçüm değerleri girildiğinde otomatik olarak tahmin yapabiliyor ve sonucu:

KÖTÜ HUYLU (M)

İYİ HUYLU (B)
şeklinde yorumluyor.

🛠️ Kullanılan Teknolojiler:
Python, Pandas, NumPy, Scikit-learn
